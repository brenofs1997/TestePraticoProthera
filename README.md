# Teste Prático Java - Gerenciamento de Funcionários

Projeto desenvolvido como parte do processo seletivo. A aplicação realiza o gerenciamento, agrupamento e operações estatísticas sobre uma lista de funcionários utilizando Java 21, Stream API e JUnit 5.

---

## 🛠️ Tecnologias Utilizadas

* **Java 21**
* **Apache Maven** (Gerenciamento de dependências e build)
* **JUnit 5** (Testes unitários)

---

## 🚀 Funcionalidades Implementadas

* **Inserção e Remoção:** Gestão de funcionários com remoção dinâmica por nome.
* **Reajuste Salarial:** Aplicação de percentual de aumento em `BigDecimal`.
* **Agrupamento:** Mapeamento de funcionários por função (`Map<String, List<Funcionario>>`).
* **Filtros e Aniversariantes:** Busca de funcionários por mês de nascimento via varargs.
* **Ordenação e Estatísticas:** Cálculo do funcionário mais velho, ordenação alfabética e soma total dos salários.
* **Cálculo de Salários Mínimos:** Mapeamento da quantidade de salários mínimos recebidos por cada colaborador.
